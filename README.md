# 경영·금융 임용 공부장

2027학년도 서울특별시교육청 중등 임용 경영·금융(상업) 전공 대비 학습용 웹 앱입니다.

## 구성
- **핵심 정리**: 교과교육학·회계·세무·무역·경영·마케팅·경제·금융·노동 36개 주제
- **기출 문제**: 2017·2018·2020~2026학년도 전공 A·B 205문항 원문 이미지와 분석 가답안
- **틀린 문제**: 틀림으로 표시한 문항 모아 보기
- **출제 분석**: 2027 예상 주제, 주제×연도 출제 매트릭스, 영역별 배점

## 사용 방법
`index.html` 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 배포하면 태블릿에서도 사용할 수 있습니다.
학습 기록(맞힘·틀림·외움)은 사용하는 브라우저에 저장됩니다.
